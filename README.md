# Diwali VR Island

A Unity VR festival island project featuring five Diwali-themed interactive venues: Rangoli, Sweet Shop, Diya, Lantern Routing, and Fireworks.

## Open the project

1. Install Unity **6000.3.19f1** with the Android build support modules if you are targeting an Android headset.
2. Open this folder (`final_project_vr`) in Unity Hub.
3. Open the main scene at `Assets/Scenes/DiwaliFestivalGround.unity`.

Unity's `Library`, `Temp`, and other generated folders are intentionally excluded from version control. Unity will regenerate them when the project opens.
